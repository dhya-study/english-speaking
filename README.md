# KDH 영어 말하기 마스터 — 공개용 웹앱

**이 폴더에는 교과서·부교재 원문이 들어 있지 않습니다.** `index.html`은 마이크 인식, 문장 비교, 파일 불러오기 기능만 제공합니다.

## GitHub Pages 배포

1. GitHub에서 새 공개 저장소를 생성합니다. 예: `english-speaking`.
2. **이 폴더에 있는 `index.html`, `.nojekyll`, `README.md`만** 저장소 최상단에 업로드합니다.
3. **절대 `KDH_43지문_개인보관용.json`을 GitHub에 업로드하지 마세요.**
4. 저장소 `Settings` → `Pages` → `Build and deployment` → `Deploy from a branch` → `main` / `(root)` → `Save`.
5. 생성된 주소 `https://<사용자명>.github.io/<저장소명>/`을 갤럭시 S26의 Chrome 주소창에서 엽니다.
6. 홈의 **지문 파일 불러오기**를 눌러 **갤럭시 다운로드 폴더에 별도로 보관한 JSON 파일**을 선택합니다.
7. 이후 같은 브라우저 주소에서 다시 접속하면 지문이 로컬 브라우저 저장공간에 유지됩니다. Chrome 사이트 데이터 삭제 또는 시크릿 모드에서는 다시 불러와야 합니다.

## 기능

- 부스터 27개, 교과서 16개, 총 290개 학습 항목
- 한국어 해석 표시 → 마이크 버튼으로 영어 음성 인식 → 단어 실시간 표시
- 마지막 단어 하나씩 취소, 전체 초기화, 이어서 말하기
- 정답 확인 시 원문 전체 공개 및 잘못된/누락된 단어 색상 구분
- 원문 기준 엄격한 비교(대소문자와 구두점 제외)
- 정답 표시 후 직접 다음 문장으로 이동
- 진도 기록, 힌트, 오답 통계 기능 없음

## 개인정보 및 권한

- 지문은 파일 불러오기 후 이 브라우저 저장 공간(localStorage)에만 저장되며 앱 자체는 지문 데이터를 어떤 서버에도 업로드하지 않습니다.
- 공개 웹앱의 코드와 URL은 다른 사람도 볼 수 있지만, **이전에 불러온 지문이 자동으로 다른 사람에게 보이지는 않습니다**.
- 브라우저 음성 인식(Web Speech API)은 **별도 서비스 서버에 마이크 음성을 전송할 수 있으며**, 인터넷 연결이 필요할 수 있습니다. 독립적이고 완전히 오프라인인 음성 인식 앱은 아닙니다.
- `file://`로 파일을 직접 여는 방식은 음성 인식이 차단될 수 있어 HTTPS GitHub Pages 주소 사용을 권장합니다.
- 다른 기기·다른 브라우저에는 지문이 자동으로 동기화되지 않습니다.
- 현재 마이크 실기기 작동은 갤럭시 S26에서 직접 확인이 필요합니다.
